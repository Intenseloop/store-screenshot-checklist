## File rules

- Upload 1 to 10 screenshots per device set.
- Use .jpeg, .jpg or .png.
- No alpha channel and no transparency.

## iPhone

App Store Connect's iPhone upload box takes the 6.3" display size: **1206 × 2622** or **1179 × 2556** in portrait (or the landscape versions). If your interface looks the same on every phone, that one set is enough, and Apple scales it down for smaller iPhones.

A set made at an older size such as 1284 × 2778 can now fail with "File dimensions are invalid". The [App Store Connect dimensions guide](https://appscreen.pro/blog/app-store-connect-file-dimensions-invalid) explains which size each upload box takes.

Apple has also announced screenshot sizes for iPhone Duo (1398 × 2034 for the outer display, 2007 × 2853 for the inner one), which it plans to require from April 2027.

## iPad

Apps that run on iPad need a 13" set. Smaller iPad sizes are optional and scale from it.

## Everything else

Mac, Apple TV, Apple Vision Pro and Apple Watch apps each need their own set. The full table of accepted sizes is in [App Store screenshot sizes for 2026](https://appscreen.pro/blog/app-store-screenshot-sizes), and Apple's source is the [screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/screenshot-specifications) page.
